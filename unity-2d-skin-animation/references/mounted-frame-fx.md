# 挂点帧特效

角色蒙皮负责姿态，外部特效独立制作；只做任务明确要求的新增元素。角色根锚点、骨骼挂点与特效发射锚点分别记录。

按用户指定审核链执行：静态特效放大＋角色组合示意→依批准图生产透明序列并交独立原速→动态批准后接Unity实际组合。允许多张参考，逐张说明形态、相对尺寸、亮度/光晕等约束。模型重绘组合图不替代角色源，也不叫实机截图。不要把长喷流当作短促枪口爆闪，或用巨大光晕代替所需形态；具体视觉以本任务批准参考为准。

生成图像用已配置的图像制作能力；真实Alpha、同画布同发射点同尺度，各帧有需要的形态/光强变化。批处理前验证实际主体数与间隔，不盲目按等格切割相邻溢出。记录校准平移与透明噪声阈值，保留原始输出。特效生产帧数/时长不是全角色常量。

序列打包复用frame-animation-packer。核帧序、逐帧/总时长、源画布、pivot与裁剪偏移，禁止裁后逐帧居中。声明量化/压缩损失，保留透明PNG；原速预览避免浏览器将极短GIF帧延长，核实际编码延时，必要时提供全色HTML/视频预览。慢放只能作为额外诊断。

接入时复用项目帧资源加载、剪裁还原和Graphic，或加最小适配。以动作时间/事件触发，不让两套独立时钟漂移。映射骨架挂点到目标Canvas局部坐标，保留色彩/材质/透明/遮罩/层级与点击穿透。附着随挂点，脱离型在触发时取姿态后独立播放，按具体语义选用。

资源预载完成再触发；同动作各发索引/消失时间、暂停和中断明确。低帧率不串发、不积压补播，结束/换卡/关闭/激活失效后无残留，迟到加载不回填。资源持有归属与运行时生成Sprite/显示实例分开记录，不销毁其他使用者共享的纹理。缺资源回退策略须符合批准范围。

单独序列通过不代表角色组合通过；保留已批准本体曲线/骨架，只替换特效时做保护哈希和定向回归。展示触发不产生伤害或投射物权威。发布另走项目流程。
