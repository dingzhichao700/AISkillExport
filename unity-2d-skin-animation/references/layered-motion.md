# 拆件与动作

单图只变形已有像素。独立肢体、关节大转角、下颌开合、枪械抬升或遮挡变化时，先列需要分离的层、前后关系、刚性区和关节覆盖，再补实际被遮挡区域。静态形象已批准不等于可以重绘角色设计；Image编辑需声明保留区和补绘区。

所有层记录源画布映射、pivot、父骨骼、初始变换及显示顺序。裁剪层保持原语义坐标，不分别拉伸/居中；关节后面不能残留旧武器/肢体。刚性武器随骨平移旋转，不随躯干软化；握持/口部关节挂点在绑定姿态和动作极值均检查。

先做能读懂的关键姿态/阶段，再细化曲线。idle、attack、roar等动作名称和数量由项目合同确定；每动作记录活动/固定区、周期或单次、幅度单位、阶段边界、回退与中断。射击可分准备/爆发/恢复，咆哮可分蓄力/张口/恢复，但不强迫每个角色共用阶段时长或相同运动。

周期要求姿态与速度接缝自然；移动根与原地动作分开。多层叠加时明确定义基础姿态重算和上层附加，避免脚本互相覆写。连续小幅关节循环可有独立相位，但仍沿用项目暂停/恢复策略。已验收动作只改幅度/节奏时保护骨架/源图/接入，并检查受影响关键姿态、切换及动作边界。

本体新动作以实际显示尺寸评估，不能靠巨大火光、抖屏或放大待机摆幅替代第二动作。用户已有批准的视觉方向先复用，新增取舍按当前批准门槛提交，不自动增加无关角色、音频/弹道或发布。
