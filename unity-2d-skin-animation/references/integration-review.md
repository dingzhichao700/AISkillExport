# 接入、增量与证据

接手先找当前实际消费者/入口、资源目录与地址、已有适配器及最新批准参数。源图不同于动画皮肤，原静态仍供其他用途时不覆盖其导入契约。已有框架能用则复用；不要复制另一角色的源尺寸、pivot、bone list或时序作为默认。

| 改动 | 最低定向核验 |
|---|---|
| 本体曲线 | 受影响完整周期/极值、暂停、前后动作切换、锚点及实际显示 |
| 拆件/骨架/网格 | 上述加权重/绑定、重导保存、遮挡/刚性、原生缓冲及消费适配 |
| 只换特效 | 本体保护、挂点/触发/尺寸/方向、全部声明帧与消失、透明/遮罩、取消回收 |
| 消费端/加载 | 正常入口与门控、静态回退、切换/重开、异步失效、共享持有/释放 |

uGUI入口用aiui-to-ugui工作流，View只投影业务状态，不新增权威资格/存档字段。实际消费者有激活或页面差异时从项目绑定的正式规范读取，不复制到通用Skill。目标为世界Sprite显示时不强行改成UI方案。

技术验证明确使用什么输入/环境，未验设备/帧率/遮罩组合不要统称通过。完整关节/蒙皮检查需授权Editor运行；只读Prefab文本与历史结果不等于新运行测试。用户要求保留预览时，记录真实Play状态，不能同时谎报Edit释放。工具状态文件可能过时，实际操作前复核进程/队列/共享时段。共享编辑器按项目规则协调，不能借用户批准本角色抢占其他现场。

保存来源、批准参考、源/Prefab/代码哈希、参数/时长、输入与生成/处理方法、运行结果和可直接查看的效果。独立预览、正式组件隔离种子、正常登录真实玩家、设备/发布分层记。旧失败结果保留原因和后续通过证据，不将历史未决误当当前待审。

完成前对照当前授权链与最近真人补充，已授权且输入齐备的余项继续执行；依赖视觉批准的阶段等待。阶段验收依项目约定记录，不以自检代替用户判断。Skill安装/验证不授权重做已有角色或运行共享Editor。

## 交给消费端的制作包

- 原图与派生图的版本/哈希/批准依据、每层画布/层序/锚点映射、正式目录清单与合法派生理由；目录按当前项目治理契约，不照搬历史案例路径。
- 可重载骨架/网格/权重、Prefab、真实驱动与动作参数；动作标识、循环/单次、触发/回空闲、时间来源、暂停/变速、中断与实例复用重置。
- 绑定姿态与静态形象一致性、动作全范围与锚点、原速预览和用户所审版本；只验证离线时明确原生运行仍待验证。
- 接入方、允许改动的消费者、静态回退和资源持有/释放契约、剩余检查及恢复信号。用户指定先预览时，不提前改页面装配。
