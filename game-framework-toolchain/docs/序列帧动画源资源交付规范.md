# 序列帧动画源资源交付规范

适用于角色动作、零散特效及其他序列帧动画。源动画生产由动画输出 Skill 负责；本工具链提供模板内的源资源导出与校验工具，不在该步骤生成图集或改变运行时行为。

本工具的执行范围止于帧动画生成、源 PNG 与 animation.json 导出及源资源验收。无需安装或启动 Unity，不执行 Unity 编译、Addressables 构建、图集打包或游戏发布。下游打包与运行时接口仅作为交接约定，不作为本工具的交付前置条件，也不列为未完成检查。仅修改本工具时运行 `Tools/Tests/test_animation_source.py` 并检查实际源输出，不触发完整工程验证或 Luban 检查。

## 目录与配置

每个动画以 `animation.json` 标识，目录名即动画名称。分类层级自由，不强制角色/动作结构：

```text
Delivery/
├── Characters/HeroKnight/Idle/
│   ├── animation.json
│   ├── 001.png
│   └── 002.png
└── Effects/Explosion/
    ├── animation.json
    ├── 001.png
    └── 002.png
```

动画目录只包含 UTF-8 `animation.json` 与最终编号 PNG，不设置 frames 子目录，不生成 character.json、action.json。预览视频、联系表、生成记录、校验报告、废弃帧和图集都放在 Delivery 根目录之外。

配置示例（数值仅演示格式，不是默认值）：

```json
{
  "duration": 800,
  "scale": 100,
  "pivot": { "x": 0.5, "y": 0.5 }
}
```

- duration 必填，为播放一次的总毫秒数，正整数且不少于帧数。按确认的目标时长填写，抽帧数量变化不得擅改时长。
- scale 为 10～200 的缩放百分比，省略时 100，交付建议显式写入。仅由下游打包工具应用；源 PNG 不提前按此值缩放。
- pivot 必填，x/y 为 0～1 数值，基于原始未裁剪画布，左下角为原点、向右和向上递增。目标时长或锚点未知时先向用户确认，工具不猜测。
- 不包含角色名、action、loop 或其他字段。名称由目录表达，循环由运行时控制。

## PNG 与实际导出

- 编号从 001.png 连续开始，纯数字且位数一致；超过 999 帧时统一四位或更多。数值顺序为播放顺序。
- 真实 Alpha 通道（RGBA 或 LA），保留半透明烟雾、光晕及柔边，不残留底色或棋盘格。
- 同一动画所有帧画布尺寸一致，覆盖完整运动/扩散范围，不同动画可不同尺寸。
- 围绕固定参考点对齐（脚底、爆炸中心、发射点等），不逐帧自动居中，不逐帧裁透明边；完整画布保留到下游打包。

模板自带 `Project/Tools/AnimationSource/animation_source.py`，依赖 Python 3.10+ 与同目录 requirements.txt。仓库内位于 `Templates/GameFramework/ProjectFiles/Tools/AnimationSource`，随既有 ProjectFiles 复制流程进入新工程；本规范随 docs 映射到 `文档/规范/通用规范`。

```powershell
python -m pip install -r Project/Tools/AnimationSource/requirements.txt
python Project/Tools/AnimationSource/animation_source.py export Approved/Idle Delivery/Characters/HeroKnight/Idle --duration 800 --pivot-x 0.5 --pivot-y 0.5 --scale 100
python Project/Tools/AnimationSource/animation_source.py validate Delivery
```

命令参数中的 800 和 0.5 必须替换为该动画确认值。export 仅读取输入同级纯数字 `.png`，按数值排序后连续重编号，拒绝数值重复的名称。输入可含生产辅助文件，但这些文件不复制进交付目录。PNG 字节原样复制，不缩放、不裁切、不移动像素；目标目录已存在则失败。临时目录通过校验后才移到目标，失败自动清理。批量动画逐个指定相对分类路径导出，再对 Delivery 整体验证。不要把源文件放在目标目录内。

validate 可接受单个动画目录或批量根目录，递归查找配置，检查配置、连续编号、文件可读性、PNG 格式、Alpha 通道及尺寸；拒绝辅助文件和动画目录中的额外子目录。输出每帧透明/半透明像素数量、可见边界及触边标记。报告写到 Delivery 外。

自动通过不代表视觉验收完成：回放并检查固定参考点、底色/棋盘格残留、软边、意外裁切、完整动作范围，以及时长和锚点是否符合确认记录。触边仅作提示（有意贴边可以合理），Alpha 通道存在也不能证明抠图质量。检查结果与联系表等保存到交付根之外。

## 下游目标接口与当前差距

目标打包工具接受单个动画或批量根目录，递归识别 animation.json；仅读取配置同级纯数字 PNG，按编号数值排序。应用 scale 一次、打包图集、写入 pivot，并均分 duration：N 帧中前 duration % N 帧使用 duration // N + 1 ms，其余使用 duration // N ms，最大相差 1ms，总和严格等于 duration。

产物写到独立输出根目录并保留相对分类路径，避免同名覆盖。例如输入根 Delivery 下的 Characters/HeroKnight/Idle 输出到 Output/Characters/HeroKnight/Idle.png 和 Idle.json。单动画输入以该目录名作为输出名；批量输入以所选根目录计算相对路径。不得在源目录中写打包结果。

现有实现核对：`FrameAnimationManager.cs` 读取已打包 JSON 的 frames、每帧 duration、pivot、sourceSize 和 spriteSourceSize，并将上起点裁剪坐标转换成下起点；`FrameAnimationView.cs` 将 pivot 直接赋给 RectTransform，符合左下角原点。`TexturePackerTool.cs` 处理 Unity Sprite 元数据，尚未实现本规范 animation.json 的递归读取、时长分配与分类输出。源配置不能直接作为当前运行时图集 JSON 使用。

因此上段是目标接口，不是当前打包器能力声明。本次源交付工具不进行坐标翻转。正式接入所选打包器前仍须核对它的 pivot、trim、scale 和输出契约；如不同，明确说明并约定转换，禁止静默转换。
