# 公共滚动提示与资源策略

状态：模板通用基线。来源为已验收的项目公共能力，项目业务与单次交付不进入模板。

## 使用方式

```csharp
GlobalToast.Show("操作成功");
GlobalToast.Warn("当前操作不可用");
GlobalToast.Clear();
GlobalToast.Shutdown(); // 登出或重建UI根前调用
```

一般瞬时反馈统一调用公共入口。持续状态说明保留在所属界面；需要用户选择的确认窗不替换。Show／Warn每次调用产生独立条目，相同内容不去重，满额后FIFO排队，等待容量默认10。条数读取模板框架常量100，普通正整数文本，初值3；项目可重新登记业务ID，不复制其他游戏配置。配置未就绪阶段使用默认3，配置就绪后缺项或非法值明确报错，解析缓存由CfgManager生命周期管理。

单行TMP文字，白色一般提示、浅金警告，独立右下Underlay且无Outline；黑色半透明两端渐隐背景用ToastGradientGraphic生成顶点，不依赖图片。模板使用自己的fontBodyCommon和fontBodyCommon_GlobalToastShadow材质。初始样式26号，超宽最小18后省略，背景高44、宽300～640；这是模板初始展示参数，不作为所有项目的设计标准。

入场0.20秒向上20像素淡入、停留1秒、0.35秒再上移28并淡出。旧条用0.18秒OutQuad让位56设计像素，途中改目标从当前显示位置接续，条目寿命不重置。按上方实际位置约束新条，中心距离至少56，避免挤开途中重叠。位移均为设计空间单位，舞台尺寸来自PortraitGameViewport，不在组件写死设备分辨率。

GlobalToastPanel与GlobalToastItem位于Login公共UI，Prefab位于title/common，生成时显式登记到title组并现场构建Addressables。UIBinder宿主导出boxMessages／itemTemplate，条目导出txtMessage；静态背景不导出。对象由既有UIFactory／PanelMgr加载和回收；宿主跨页面保留，条目池随配置容量调整，关闭清理Timer监听与过期加载代次。

## UI基础契约

BasePanel.KeepOpenOnCloseAll控制批量关闭时是否保留，LoadingPanel及GlobalToastPanel显式选择保留。ReceivesPanelInput控制是否参与键盘目标选择，被动提示关闭，普通窗口行为保持。模板保留既有窗口布局与动画，不因本次回写统一改动所有窗口；FitContentToSafeArea默认关闭，新提示宿主显式启用PanelSafeContent。设计尺寸由RookieEngine传入PanelMgr，旧四参数调用按所给舞台尺寸兼容。

UIScreenRegions统一设备安全区和平台保留区域，SafeAreaFitter与PanelSafeContent消费其结果。Login的GameUIScreenRegions负责微信胶囊提供器；微信代码只在对应平台宏下编译，其他平台使用设备安全区。微信真机验收与Editor验证分别记录，不能用桌面模拟声明真机通过。

## ResourcePresentation边界

Foundation持有ResourcePresentation、IResourcePresentationPolicy和ImageResource，负责稳定契约和公共加载机制；Login的GameResourcePresentationPolicy／ResourceConst／AudioConst／UIEnum提供资源目录、窗口标识、音效ID映射和默认帧材质。Foundation不得反向依赖Login／Main。

LoginEntry必须在打开任何窗口或查询资源约定前安装同一项目策略；Editor独立预览由ResourcePresentationEditorSetup安装。未安装策略明确报错，不静默使用固定路径。UIFactory、UITools、AudioManager、GameButton及帧动画通过策略查询项目约定，真正加载仍由ResourceLoader／ResourceManager完成。

旧字符串图片入口按项目策略转换，新增代码可传入ImageResource完整Address／ResType／SpriteName，不按目录猜测类型。策略随启动安装，不把它当成同进程随意切换已加载资源版本的接口。测试替代策略必须finally恢复。

## 验证与维护

运行Tools/Test-GameFrameworkTemplate.ps1核查基线及JSON/bin工具链；独立工程生成必须重新构建Addressables，不携带缓存。FrameworkTemplateValidation.RunPlayMode在实际Opening→Login→Option→Loading→Main之后执行GlobalToastBaselineValidation，验证资源策略程序集边界、真实资源加载、重复叠加、向上让位、单行／穿透、队列回收、确认框之上及跨页保留。

标准化回写不复制业务界面、卡牌／战斗数据、项目常量号段、单次任务脚本、截图、日志、Figma标识或Library。已有GUID和无关修改保留。组件、真实启动、资源构建与真机分别记录；修改Foundation契约后，下一次发布需匹配底座，不声称可直接替换旧底座上的业务DLL。
