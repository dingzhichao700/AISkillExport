# 帧阴影组件规范

状态：现行。2026-10-29从已验收样例提取；不包含样例兵种、层级编号、配置ID、默认角度或素材。

## 接口和坐标

模板提供 Foundation 的 `FrameShadowGraphic : MaskableGraphic`。调用方按当前动画帧调用 `SetFrame(sprite, framePivot, mirror, ground, altitude, angle, length, alpha)`。

- `framePivot` 是完整画布语义锚点换算到裁剪Sprite区域后的像素位置：原画布尺寸×归一化pivot−裁剪偏移。不可用Sprite区域中心代替。
- `ground` 是父节点内从左上开始的X右Y下坐标；组件锚点固定左上。本体和阴影父层应共享相同场景原点与相机变换。
- `altitude` 为有限非负离地高度；`angle` 从水平向左朝下旋转，范围(0,180)度；`length` 为有限正数；`alpha` 在[0,1]。全部参数由调用方配置，不读取业务表。
- UI局部Y向上，D=length×(−cos(angle),−sin(angle))。源点相对语义锚点为(x,y)，投影=(mirror ? −x : x,0)+D×y，高度平移为D×altitude。镜像先于投影，不能镜像光照方向。
- `Bounds` 返回相同输入下的场景X右Y下包围框；静态几何方法要求调用方传入有效参数。支持矩形、未旋转打包的Sprite帧；不支持旋转打包或紧密多边形图集。

## 生命周期职责

- 组件复用Sprite及图集，不复制像素或另设动画时钟。调用方负责保持源资源存活、同步本体同一帧及锚点。
- 本体和阴影的层级由业务决定。调用方用二者包围框联合判断可见性；仅影子在视窗内时仍须保留。相机缩放只应用一次。
- 调用方管理配对池化与单位生命周期；`ResetFrame` 清空Sprite引用、颜色、位置、缩放、旋转并禁用对象，重新使用时先启用再设置帧。回收表现不得销毁逻辑单位。
- 视觉高度不隐含通行类型或目标资格；血条和弹道挂点等依赖表现由业务层同步。

## 验证

运行 `Tools/Test-FrameShadow.ps1 -UnityEditor <Unity.exe绝对路径> -OutputRoot <独立测试目录>`。脚本只从模板复制组件到新建的最小隔离Unity工程，编译并执行实际uGUI网格、UV/共享纹理、镜像锚点、方向、高度、包围框与回收验证；不读取样例工程，不产生或回写Addressables缓存。测试目录保留日志用于诊断。

组件验证不等于项目完整接入：各项目还需检查所有实际动作帧、联合剔除、配对回收、相机缩放及附件表现，并独立记录用户视觉验收。像素风格和参数默认值归项目，不固化到模板。
