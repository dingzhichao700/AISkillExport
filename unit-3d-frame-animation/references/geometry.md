# 几何与定标

方向数、正交/透视、投影关系由项目确定。用模型正前向向量的屏幕投影确认方向，不凭相机名字或世界轴符号。可镜像的前提是项目接受左右差异，围绕语义pivot还原裁剪偏移。

同一3D模型所有相机共用模型变换、正交尺度、分辨率及导出比例。不同视角可见包围框不同是正常透视/遮挡，不按方向单独放大。同一中立姿态的稳定头部/头盔高度用于尺度标尺，注明是否包括背包天线；举枪最高点不能当常态体量。

中立姿态选固定地面原点，角色可用双脚接地点的代表中点；非落地部件用安装定位点。相机偏移让该点投影到目标画布锚点。全动作保留此坐标，不逐帧重算脚底。若动作带root motion，先记录位移及项目策略，不能私自抵消。

版本化geometry记录：画布、模型单位/变换、地面/安装坐标与语义、稳定高度标尺、每相机完整变换/投影模式/正交尺度、目标pivot、参考动作及帧、fps、超采样、缩小方式、渲染器/色彩管理。左上像素点(px,py)转交付左下归一化为(px/W,1-py/H)。

静态证据同时提供干净PNG、标注倍率放大、目标战斗场景1:1、与已有单位/建筑的同尺度对照、相同画布布局的实际锚点诊断。场景尺寸经用户确认后才能批量制作动作；正式输出前按同一几何版本复核。记录像素/世界单位换算、导出scale和运行时缩放，避免重复放大；场景底图或比例未知时明确缺输入，不能自行标记确认。全动作投影/Alpha检查安全边距；确实越界时共同扩画布或修相机并重验全部受影响项，不单独缩一帧。
