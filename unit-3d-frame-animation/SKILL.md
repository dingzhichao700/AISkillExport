# 3D单位转帧动画

先确定当前阶段，复用已批准模型、动作和几何，完成可审核的当前产物。已有骨骼动作直接离线渲染，不再调用图生视频或背景抠取。原生3D材质与网格修改使用建模工具；新增或重绘位图贴图按环境的Image生成/编辑规则另走相应工具。

## 建立制作契约

读取项目入口、资源/动作/光照/阶段验收规范及已有专项契约。记录源模型、角色、目标风格、所需动作/方向、显示尺寸与画布、地面或安装锚点、允许镜像关系、渲染器和材质版本、输出位置与当前授权。参数来自项目或批准记录，不套用本次样板的数值。

- 导入、缺图和骨骼整理：读[模型与材质](references/model-material.md)。
- 新机位、尺度或锚点：读[几何与定标](references/geometry.md)。
- 动作选择、渲染或材质动作回归：读[动作与渲染](references/motion-render.md)。
- PNG、JSON、图集及工程落地：读[交付与验证](references/delivery.md)。
- 场景尺寸确认、验收入口、整包交付与最终回复：必读[验收与交付关卡](references/review-contract.md)。
- 接续异星军团样板时再读[项目接续索引](references/starfront-case.md)；历史参数不构成新模型默认值。

## 阶段与审核

| 阶段 | 必需证据 | 后续条件 |
|---|---|---|
| 模型整理 | 来源、工具/导入器版本、网格/UV/骨骼/材质/动作清单、缺项 | 可编辑源可独立重开，缺项影响明确 |
| 静态定标 | 所需源方向干净PNG、放大与原尺寸、目标战斗场景内与已有单位/建筑的尺度对照、锚点诊断 | 用户确认场景显示尺寸后锁定几何，再批量制作动作；无场景输入则明确缺项，不以透明底预览替代 |
| 动作审核 | 项目要求的动作顺序、各方向原速完整周期或一次性过程 | 对应动作及其时长获确认 |
| 序列交付 | 完整透明帧、配置、全帧结构检查及视觉证据 | 小尺寸表现、连续性与定位审核完成 |
| 接入 | 独立打包校验、引用/导入设置检查、实际切换 | 工程与运行分别记录验收 |

用户已明确授权的阶段不重复询问。请求跨阶段试验时可产出对应样件，注明未验收；仅新模型或材质候选不能自动继承旧视觉通过。技术检查通过不等于视觉或战斗通过。

## 不变量

- 同一模型各朝向共用比例、正交尺度和导出比例；不得各自按包围框适配。
- 脚下或安装点只标定一次，动作/转向时不追随最低脚底；不逐帧居中。
- 按真实部件网格分材质。禁止仅凭屏幕颜色、骨名或高度阈值猜炮管/头盔范围。
- 切换动作恢复默认通道；使用源片段定义与原速，循环排除重复边界，攻击保留准备和恢复。
- 无授权不插帧、反播、变速、裁短动作或修改发射/命中规则。发现业务时长截断动画时记录冲突，交业务实现处理。
- 输出真实RGBA，不烘焙地面、棋盘格、血条或辅助标记；灯光、阴影和金属效果遵守项目及本轮用户授权。
- 在最终显示分辨率添加描边；宽度可配置，不默认全项目1px。
- 源工程、工作渲染、审核证据、交付和工程资源分离；保留版本/哈希与可回退源。

## 工具

`scripts/render_blender.py` 是已测试的骨骼Action离线渲染工具：先准备好源blend及机位，再按[渲染配置](references/motion-render.md)执行。它不自动定标、不修模型、不分材质、不替代视觉审核；首次使用先导出少量样帧。

`scripts/validate_sequences.py <delivery-root> --report <evidence.json>` 检查目录、编号、时长、锚点、PNG尺寸/Alpha/透明边缘。需要Python与Pillow。检查不改PNG；必要时先安装到工作环境，不绑定个人虚拟环境路径。

图集使用可用的frame-animation-packer，游戏接入遵守目标工程规范；此Skill不默认发布、构建或改玩法/存档。并行UI开发时不擅自切场景、进Play或触发全工程刷新；可先按授权落地资源并准确标记待导入/待运行验证。

正式交付按验收与交付关卡逐项检查，直接提供原尺寸场景切换预览、独立ZIP及大小、检查结果和明确待验收项。每个“单位×动作×朝向”默认是一个完整可独立播放的本体动画；不擅自拆段或分层组合。资源场景验收不自动扩大为完整卡牌业务接入。

`scripts/review_delivery.py`提供场景尺度对照、已合成预览帧编码、交付清单检查与ZIP逐文件哈希验证，参数及限制见上述关卡。它不代替用户批准、全帧检查或游戏运行验收。
